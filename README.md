# Groundwork NYC Research Demo

Static interactive demo of the November 5 two-stage research connection.
The score uses 60% archive-persistence percentile and 40% the original
price-independent cuisine-gap score. Guest price is not a ranking input.
Monthly lease budget filters the synthetic property inventory separately.

The default Korean scenario's top five identifiers and scores match the Flask
dashboard. All properties are synthetic, not verified available listings.
Archive persistence is not verified permanent-closure or survival prediction.
No account database or restaurant-level training records are included.

## Enable GitHub Pages

A repository admin or maintainer must select:

Settings > Pages > Build and deployment > Deploy from a branch

- Branch: gh-pages
- Folder: / (root)
- Save

After GitHub confirms a successful deployment, the default project URL is:
https://rumiakitinari.github.io/GroundworkNYC/

This branch contains only demo files. It does not change the main application,
model selection, or main branch. Validation provenance is in validation.json.
