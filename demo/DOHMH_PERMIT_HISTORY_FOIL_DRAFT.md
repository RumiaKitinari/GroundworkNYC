# Draft: DOHMH Historical Food-Service Permit Records Request

**Status:** Draft only. Not sent. Review the requester name, contact details,
scope, and any institutional requirements before submitting.

**To:** recordsaccess@health.nyc.gov
**Subject:** FOIL request: historical NYC food-service establishment permit status and lifecycle records, 2022-2026

Dear Records Access Officer,

Under the New York Freedom of Information Law, I request an electronic copy of
existing records for New York City food-service establishments covering
January 1, 2022 through October 20, 2026. This request is for a university
capstone research project studying how to evaluate restaurant-location
suitability. Please provide records for establishments that ceased operating
as well as those currently active; the public restaurant-inspection feed
contains active establishments only and cannot establish historical exits.

Specifically, please provide any existing machine-readable permit or
establishment-status history with the following fields, where maintained:

- CAMIS/permit identifier; establishment name, address, borough, and ZIP code;
  permit type; issue, effective, renewal, expiration, and termination dates.
- Each status change, its effective and recorded dates, status and reason codes,
  and code definitions, including surrender, cancellation, nonrenewal,
  suspension, revocation, closure, reopening, and administrative inactivity.
- Existing identifiers or crosswalk fields linking predecessor/successor CAMIS
  records when an establishment changes owner, name, address, or permit.
- Available record-layout documentation explaining whether a status means
  permanent cessation, temporary health closure, relocation, ownership
  transfer, or simply expiration of an individual permit.

An existing CSV export or database extract is preferable; no new analysis is
requested. If a complete extract is unavailable or would be unusually
burdensome, please describe the records that do exist and whether the request
can be narrowed to a supplied list of CAMIS identifiers or a shorter date
range. Please provide releasable records electronically and advise of any
expected fees before processing if fees would apply. If another office
maintains these records, please direct me to that office.

Thank you,
